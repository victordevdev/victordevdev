## Projets Trail & Running

### RunCut
> Generateur de plan de course trail et running a partir d'un fichier GPX

- **Backend** : Java 17, Gradle (zero Spring)
- **Frontend** : Next.js 16, shadcn/ui, Recharts
- **Algo** : Modele empirique trail, fatigue non-lineaire, technicite terrain ajustable
- **Features** : Pacing km par km, gestion ravitaillements, profil altimetrique, export CSV/PNG

[runcut.victordevdev.ovh](https://runcut.victordevdev.ovh)

---

### MyFinishTime
> Estime ton temps d'arrivee sur les courses UTMB World Series

- **Frontend** : Next.js, TypeScript
- **Backend** : FastAPI, Python, scikit-learn
- **Data** : Supabase PostgreSQL, 200+ courses, 124 000+ resultats reels
- **Features** : Prediction par UTMB Index, comparaison de courses, statistiques detaillees

[mft.victordevdev.ovh](https://mft.victordevdev.ovh)

---

### TrailReview *(prochainement)*
> Decouvrir et mettre en avant les petites courses de trail qui meritent d'etre connues

- **Stack** : Next.js 16, React 19, Prisma 7, PostgreSQL, NextAuth 5
- **Features** : 230+ courses, reviews multi-criteres, comparateur radar, carte Leaflet, badges

## Deploiement & Infra

> Chaque projet est deploye automatiquement sur un VPS arm64 (Hetzner) via CI/CD GitHub Actions.

- **Pipeline** : Push sur `main` → build Docker → push Docker Hub → deploy SSH automatique
- **Reverse proxy** : Traefik v3, HTTPS automatique (Let's Encrypt), multi-services
- **Temps de deploy** : ~3 min du commit au live
- **Stack** : Docker Compose, images arm64 natives, QEMU pour cross-compilation
